# Pac-Man

Pac-Man es un clásico juego arcade en el que controlas a un personaje amarillo que debe comerse todos los puntos de un laberinto mientras huye de cuatro fantasmas. El objetivo es completar cada nivel sin ser atrapado, usando los túneles y las píldoras de poder para darse la vuelta y comer fantasmas.
